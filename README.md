# NOCTURNE II — ECLIPSE EDITION 🌘

**Бесконечный пиксельный экшен-платформер, который запускается прямо в браузере.**

🎮 **Играть:** https://okun4062-cmd.github.io/game/index.html

Никаких сборщиков, библиотек и серверов: сайт работает на обычном GitHub Pages.

## Что нового во второй версии

- **Локации в 2,7 раза длиннее:** по 3200 игровых единиц до каждого финального босса. После 12 миров путешествие продолжается.
- **12 визуальных тем и 12 легендарных боссов:** каждый со своим образом, цветовой палитрой, атаками и усиленной второй фазой.
- **Мини-боссы:** элитный страж в середине каждого региона, с отдельной шкалой здоровья и наградой за победу.
- **Секреты и исследование:** 2 скрытых святилища, 5 светящихся осколков света и платформы в каждом регионе.
- **Опасности:** ловушки, группы врагов, снаряды и арены со зрелищными атаками.
- **Сохранение прогресса:** два маяка на регион; чекпоинты, кристаллы, побеждённые мини-боссы и рекорд хранятся в браузере.
- **Кинематографичный пиксельный мир:** многоуровневый параллакс, луна и затмения, архитектура, погодные эффекты, свечение, анимация персонажа и глубина сцены.
- **Телефон и ПК:** сенсорные кнопки, полноэкранный режим и отдельная кнопка выхода из полного экрана.
- **Звуковые эффекты по желанию:** кнопка звука выключена по умолчанию.

## Управление

| Действие | Компьютер | Телефон |
|---|---|---|
| Движение | A / D или ← / → | ◀ ▶ |
| Прыжок + двойной прыжок | Space / W / ↑ | ▲ |
| Атака | J / X | ⚔ |
| Рывок | Shift / C / K | ◆ |
| Пауза | Esc / P | Ⅱ |
| Полный экран | Кнопка в шапке или внутри игры | ⛶ |

## Публикация

1. В репозитории откройте **Settings → Pages**.
2. Выберите **Deploy from a branch → main → /(root)**.
3. Откройте https://okun4062-cmd.github.io/game/index.html .

Все игровые файлы находятся в корне. Главный файл — `index.html`; никаких зависимостей и скачиваний.

## Сохранение

Прогресс пишется в `localStorage` браузера под ключом `nocturne-eclipse-save-v2`. При первой загрузке выберите **Новое приключение**. Когда появится прогресс, на стартовом экране станет доступно **Продолжить сохранение**. Сохранение привязано к устройству и браузеру.

## Описание разработки

Графика процедурно рисуется на HTML Canvas 2D. Игра рассчитана на 60 FPS с фиксированными шагами физики и неприхотливым управлением. Нет чужих изображений и внешних JS-библиотек.

**Примечание:** высокая сложность поздних миров — часть бесконечного режима. Для лучшей игры на телефоне разверните полноэкранный режим горизонтально.
