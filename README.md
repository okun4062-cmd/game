# Вечный Горизонт

Сайт оригинальной пиксельной метроидвании о спуске к чёрной дыре: сюжет, пять уровней, играбельное демо прямо на странице, герой и бестиарий.

Весь сайт — один файл `index.html` без сборки и зависимостей (шрифты подгружаются с Google Fonts). Откройте его в браузере или включите GitHub Pages (Settings → Pages → ветка `main`, папка `/`).

## Управление в демо
| Действие | Клавиши |
|---|---|
| Движение | ← → |
| Прыжок / двойной прыжок | Пробел / Z |
| Удар иглой | X / J |
| Удар вверх / вниз | ↑ / ↓ + удар |
| Рывок | Shift / C |
| Пауза | Esc |

Стиль и токены дизайна описаны в `DESIGN.md`.
