# NOCTURNE ∞ — Бесконечное королевство

Играбельный пиксельный экшен-платформер без сборки. Весь код и графика находятся в `index.html`. Сайт опубликован через GitHub Pages: https://okun4062-cmd.github.io/game/index.html

## Возможности
- Процедурно продолжающиеся области, 12 типов биомов с повторением на повышающихся этапах.
- 12 уникальных визуальных типов боссов с разными атаками и аренами; битвы продолжаются без конечного уровня.
- Враги, двойной прыжок, атаки, рывок, восстановление здоровья и контрольные рубежи.
- Сенсорное управление для телефонов, полноэкранный режим, клавиатура.
- Звуковые эффекты (по кнопке), пауза, счётчик и локальное сохранение рекорда.

## Управление
- **A/D** или **←/→**: ходить.
- **Space**, **W**, **↑**: двойной прыжок.
- **J**, **X**, **K**: атака.
- **Shift** или **C**: рывок.
- **Esc** или **P**: пауза.
- На мобильном: экранные кнопки ◀ ▶ ◆ ⚔ ↑.

## Запуск
Откройте `index.html` в браузере или [играйте на GitHub Pages](https://okun4062-cmd.github.io/game/index.html). GitHub Pages должен быть настроен на **main / (root)**.

Примечание: босс не пропускается; после победы можно идти вправо в следующий мир. Рекорд хранится в браузере (`localStorage`).
